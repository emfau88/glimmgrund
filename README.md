# Glimmgrund

[▶ Glimmgrund im Browser spielen](https://emfau88.github.io/glimmgrund/)

Ein kleines Echtzeit-Aufbauspiel für Handy und Desktop. Unter der Mooswiege warten Pilzbeete, Erzadern und neugierige Höhlenkäfer. Du gibst deiner Mannschaft Aufträge und entscheidest, wohin das Dorf wächst.

## Die ersten zwei Minuten

1. Wähle **Graben** und tippe auf einen gold umrandeten Felsen. Markiere gleich die nächsten Felder. Pip läuft hin und gräbt sie der Reihe nach frei. Eine Zahl zeigt jeden Auftrag. Tippe erneut, um ihn zurückzunehmen.
2. Schau links am Pilzgarten nach Luma. Sie pflückt Pilze und bringt sie zum Sammelkorb. Über **Nahrung** kannst du zusätzlich selbst ernten. Die Vorräte und die Arbeit laufen während des Spielens weiter.
3. Öffne **Bauen**, wähle einen Pilzgarten und tippe auf einen freigegrabenen Stollen. Über **Anwerben** kannst du weitere Bewohner holen. Tippe einen Bewohner an, um seinen Arbeitsplatz zu ändern.
4. Im **Höhlenbuch** findest du dein nächstes Ziel und die Chronik. Nach drei Grabungen kannst du am Tor die ersten Käfer anlocken.

## Bedienung

Mit einem Finger verschiebst du die Karte, mit zwei Fingern kannst du zoomen und drehen. Auf dem Desktop funktionieren auch Ziehen mit der Maus und das Mausrad. Die Tasten **1–4** wählen die Werkzeuge, **Q/E** drehen die Karte und die **Leertaste** pausiert.

Ein Spieltag dauert 90 Sekunden aktive Spielzeit. Pause und ein Wechsel in den Hintergrund halten die Zeit an. Der Spielstand einschließlich angefangener Grabaufträge wird in diesem Browser gespeichert.

## Lokal spielen

Lade `index.html` herunter und öffne die Datei in einem aktuellen Browser. Spiel, Grafiken und Schriften stecken in dieser einen Datei. Die 3D-Karte nutzt WebGL oder den eingebauten Software-Renderer. Für die lokale Version brauchst du weder einen Server noch eine Installation.

GitHub Actions veröffentlicht die HTML-Datei bei jedem Push auf `main` auf GitHub Pages.
